Load a ROM or BIN image to inspect it.

Add module files to replace modules in this ROM or add new ones. A replacement with the same name as an existing module overwrites it in place when it fits in the old space, and the ROM keeps its size. Anything that doesn’t fit, and any new module such as icon.library, workbench.library or ehide.device, goes in a second 512 KB area. That makes a 1 MB image: one 27C800 for A500+/A600, or two 27C400 (HI/LO) for the A1200. The second area works on Hyperion Kickstarts (3.1.4, 3.2), 3.1 (40.68) and 2.05 (37.350). On the older ones the scan table has no room to grow, so the scan of $F00000–$F80000 (CDTV-style expansion ROMs) is dropped to make room. Use module files saved from the Modules tab, or Amiga executables that contain a resident tag. Not tested on real hardware — try the result in an emulator first.
